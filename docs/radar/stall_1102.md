# 실험 칸 실측 정리 (record_1102)

- 장소: 우정원 7층 여자화장실, 실험 칸 1곳
- 녹화: 2026-11-02 (record_1102, 56개 파일)
- 측정: 아이폰 측정 앱. 여러 사진의 값을 교차 검증해 보정
- 오차: 직선 모서리 ±1 cm, 둥근 면·비스듬한 각도 ±2 cm, 1 m 이상 ±2~3 cm
- 측정 앱 검증: 슬림캔(실제 높이 13.3 cm)을 13 cm로 잼(−2%). 비율 보정 없이 원값을 쓴다
- `≈` 표시는 직접 재지 않고 다른 치수로 계산한 값

## 0. 방향과 좌표

**왼쪽/오른쪽 = 문 앞에 서서 변기를 바라볼 때 기준**

| | 무엇이 있나 |
|---|---|
| 왼쪽 벽 | 휴지 디스펜서, 레이더 봉 고정판, 전선 몰딩, ADT 박스 |
| 오른쪽 칸막이 | 위생용품 함 |
| 뒷벽 (변기 쪽, 타일) | 변기, 세정 밸브, 선반, 어댑터, 콘센트 |
| 앞 (문 쪽) | 왼쪽에 고정 칸막이 38 cm, 오른쪽에 문 59 cm |

칸 좌표 (`stall_1102.json`, 단위 m)
- 원점: 뒷벽과 왼쪽 벽이 만나는 모서리의 바닥
- X: 왼쪽 벽 → 오른쪽 칸막이 (0 ~ 0.97)
- Y: 뒷벽 → 문 (0 ~ 1.375)
- Z: 바닥 → 위 (0 ~ 2.28)

이 좌표는 왼손 좌표계다(위에서 내려다보면 X·Y가 거울상). 그래서 레이더가 문 쪽을 볼 때 `mirror_x: true`가 맞다. `calibrate.py` 2단계에서 데이터로 확인한다.

## 4. 레이더 설치

| 항목 | 값 | 상태 |
|---|---|---|
| 설치 방식 | 왼쪽 벽 고정판(높이 7 cm)에서 나온 검은 봉 끝에 레이더를 닮 | 사진 확인 |
| X (왼쪽 벽에서) | 0.63 m (고정판 ~ 기기 63 cm) | 실측. 기기 중심인지 가장자리인지 ±5 cm |
| Y (뒷벽에서) | 0.23 m | 실측 |
| Z (바닥에서) | 약 2.00 m (±5 cm) | 사진 치수로 계산: 봉은 칸막이 상단(≈213)의 고정판(7 cm) 높이 → 봉 중심 ≈ 2.09, 레이더는 봉 끝 아래에 달려 중심이 약 10 cm 아래. 칸막이 213 자체가 계산값이라 ±5 cm |
| 바라보는 방향 (yaw) | 문 쪽, 90° (가정) | 사진상 문 쪽을 봄 |
| 아래로 숙인 각도 (pitch) | **45° (가정)** | **유일하게 모르는 값.** 캔은 안 찍혔고(정지 물체를 센서가 지움), 흔들린 문은 밖의 사람까지 같이 찍혀 실패 |
| 거꾸로 매달림 (roll) | 0° (가정) | `calibrate.py` 1단계에서 확인 |
| 전원 | 어댑터는 선반 아래 왼쪽, 콘센트는 변기 뒤 왼쪽 | |

**pitch 재는 법**: 아이폰 측정 앱의 '수준기' 탭을 레이더 앞면에 대면 기울기가 나온다. 수평에서 몇 도 숙였는지 적는다.
