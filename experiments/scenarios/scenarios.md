# 실험 시나리오

계획서의 시나리오 구성을 옮긴 초안입니다. ID는 데이터 파일 이름에 그대로 씁니다.
시나리오당 복수 참가자, 20회 이상 반복을 목표로 합니다.

| ID | 구분 | 동작 | 목적 |
| --- | --- | --- | --- |
| install-vent | 설치 | 환풍구에 부착 | 탐지 대상 |
| install-shelf | 설치 | 선반 위에 배치 | 탐지 대상 |
| install-wall | 설치 | 벽면 상단에 부착 | 탐지 대상 |
| normal-enter | 정상 | 입장/퇴장 | 기본 오탐 측정 |
| normal-sit | 정상 | 앉기/서기 | 기본 오탐 측정 |
| confuse-towel | 혼동 | 수건 걸기 | 어려운 오탐 측정 |
| confuse-clean | 혼동 | 청소 | 어려운 오탐 측정 |
| confuse-lean | 혼동 | 벽 짚고 몸 지탱 | 어려운 오탐 측정 |
| confuse-shelf | 혼동 | 선반에 물건 올리기 | 어려운 오탐 측정 |
| disturb-phone-towel | 교란 | 휴대폰 영상 시청하며 수건 걸기 | 두 센서 동시 오반응 측정 |

ROI(관심 구역) 좌표, 레이더 설치 위치, 참가자 안내 문구는 프로토콜 문서가 정해지면 `docs/`에 추가합니다.
